# ChainTheory

The compendium's main Lean package. Its two libraries:
- **`ChainTheory`** has one module per chapter of the compendium, data modules with finite checks, three kernel modules, and the open results as opaque propositions.
- **`AlphaDerivation`** is an earlier alpha derivation, which the chapters build on.

It requires `AxiomDeclarationTwo`, `KernelDerivationC` and `ActClosureCapFree` from the folders beside it. See [`../README.md`](../README.md).
